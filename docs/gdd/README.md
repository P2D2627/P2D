## Convenções

- A personagem é "a alma", sem género.
- Os nomes das mecânicas e dos parâmetros ficam em inglês, como no jogo e no Inspector.
- Cada número vem do jogo ou de um documento do repositório, com a fonte.
- `[por decidir pelo grupo]` marca o que ainda não está decidido.
- Os diagramas estão em Mermaid; o GitHub desenha-os.

## Manutenção

- Uma mudança de design altera o bloco no mesmo pull request da feature.
- Quem revê um bloco atualiza a data de revisão.
- O detalhe vive no README e no `docs/`; o GDD liga, não copia.
